# Villefranche 2026–2032 · Programme PCF (site prêt Vite + Tailwind)

Programme municipal **mis à disposition des futures listes** pour les municipales à Villefranche‑de‑Rouergue.

## Démarrer en local
```bash
npm install
npm run dev
```
Ouvre ensuite http://localhost:5173

## Construire et déployer (Vercel/Netlify)
```bash
npm run build
```
Le dossier `dist/` peut être déployé tel quel.

## Modifier le contenu
Le contenu est centralisé dans `src/content.js` (intro, indicateurs, sections, exemples).

## Imprimer/PDF
Bouton **Imprimer / PDF** inclus. La page « Programme complet » (#programme-complet) regroupe tout le programme.
